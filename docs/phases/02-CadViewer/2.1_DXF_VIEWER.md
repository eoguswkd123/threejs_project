## 1. Overview (개요)

### 1.1 목표

프론트엔드에서 DXF 파일을 파싱하여 3D 와이어프레임으로 렌더링 (백엔드 불필요)

### 1.2 MVP 범위

| 항목          | MVP 범위              | 확장 단계                                |
| ------------- | --------------------- | ---------------------------------------- |
| **파일 형식** | DXF (ASCII)           | DWG, PDF (Phase 2.2)                     |
| **엔티티**    | LINE                  | ARC, CIRCLE, POLYLINE ✅                 |
| **HATCH**     | -                     | 2D 면 채우기 ✅, 3D 돌출 ✅              |
| **레이어**    | 단일 레이어           | 레이어별 색상/가시성 ✅                  |
| **UI**        | 파일 업로드 + 3D 뷰어 | 레이어 패널 ✅, 렌더링 토글 ✅           |
| **3D 렌더링** | -                     | HATCH 3D ✅, ShadingMode (4가지 모드) ✅ |
| **성능**      | 기본                  | 2D WebWorker/LOD ✅, 3D 최적화 ✅        |

### 1.3 기술적 제약

- DXF ASCII 형식만 지원 (바이너리 DXF 미지원)
- 파일 크기 제한: 20MB
- WebWorker 사용 조건: 파일 > 2MB

### 2.3 데이터 흐름

```
File Drop → FilePanelViewer → useDxfLoader → ParsedCADData → CadMeshViewer → Three.js Render
                                    ↓
                              (파일 > 2MB)
                                    ↓
                              useDxfWorker (WebWorker)

상태 흐름:
1. File → text() → dxf-parser
2. entities → entityParsers → ParsedLine/Circle/Arc/Polyline/Hatch/Text/...
3. dxfToGeometry() → BufferGeometry (레이어별)
4. CadMeshViewer → WireframeMesh/HatchMesh/TextMesh/... → Three.js 렌더링
```

```typescript
        polylinesToGeometry(filterByLayer(data.polylines, visibleLayers))

    const merged = mergeBufferGeometries(
        geometries.filter((g) => g.attributes.position?.count > 0)
```

```typescript
export function ellipsesToGeometry(
    ellipses: ParsedEllipse[],
    segments = 64
): THREE.BufferGeometry {
    const vertices: number[] = [];

    for (const ellipse of ellipses) {
        // 장축 길이 및 단축 길이 계산
        const majorLength = Math.sqrt(
            ellipse.majorAxisEnd.x ** 2 + ellipse.majorAxisEnd.y ** 2
        );
        const minorLength = majorLength * ellipse.minorAxisRatio;

        // 장축 회전 각도
        const rotation = Math.atan2(
            ellipse.majorAxisEnd.y,
            ellipse.majorAxisEnd.x
        );

        const curve = new THREE.EllipseCurve(
            ellipse.center.x,
            ellipse.center.y,
            majorLength, // xRadius (장축)
            minorLength, // yRadius (단축)
            ellipse.startParam, // 시작 파라미터 (0 = 전체)
            ellipse.endParam, // 끝 파라미터 (2π = 전체)
            false, // clockwise
            rotation // 회전 각도
        );

        const points = curve.getPoints(segments);
        for (let i = 0; i < points.length - 1; i++) {
            vertices.push(points[i].x, points[i].y, ellipse.center.z);
            vertices.push(points[i + 1].x, points[i + 1].y, ellipse.center.z);
        }
    }

    const geometry = new THREE.BufferGeometry();
    geometry.setAttribute(
        'position',
        new THREE.Float32BufferAttribute(vertices, 3)
    );
    return geometry;
}
```

```typescript
export function splinesToGeometry(
    splines: ParsedSpline[],
    segments = 64
): THREE.BufferGeometry {
    const vertices: number[] = [];

    for (const spline of splines) {
        // 제어점을 Vector3로 변환
        const points = spline.controlPoints.map(
            (p) => new THREE.Vector3(p.x, p.y, p.z)
        );

        // CatmullRomCurve3 사용 (B-스플라인 근사)
        const curve = new THREE.CatmullRomCurve3(
            points,
            spline.closed, // 닫힌 곡선 여부
            'catmullrom', // 곡선 타입: 'catmullrom' | 'centripetal' | 'chordal'
            0.5 // tension (0 = 직선에 가까움, 1 = 부드러움)
        );

        // LOD 기반 세그먼트 조절
        const segmentCount = Math.max(
            segments,
            spline.controlPoints.length * 10
        );
        const curvePoints = curve.getPoints(segmentCount);

        for (let i = 0; i < curvePoints.length - 1; i++) {
            vertices.push(curvePoints[i].x, curvePoints[i].y, curvePoints[i].z);
            vertices.push(
                curvePoints[i + 1].x,
                curvePoints[i + 1].y,
                curvePoints[i + 1].z
            );
        }
    }

    const geometry = new THREE.BufferGeometry();
    geometry.setAttribute(
        'position',
        new THREE.Float32BufferAttribute(vertices, 3)
    );
    return geometry;
}
```

```typescript
interface EntityParser<T extends ParsedEntity> {
    /** 이 파서가 해당 엔티티를 처리할 수 있는지 확인 */
    canParse(entity: DxfEntity): boolean;
    /** DXF 엔티티를 ParsedEntity로 변환 */

}

// 지오메트리 변환기 인터페이스
interface GeometryConverter<T extends ParsedEntity> {
    /** ParsedEntity를 Three.js 지오메트리로 변환 */
    convert(
        parsed: T[],
        options?: ConvertOptions
    ): THREE.BufferGeometry | THREE.Group;
}

// 변환 옵션
interface ConvertOptions {
    segments?: number; // LOD 세그먼트 수
    font?: string; // 폰트 경로 (텍스트용)
    arrowSize?: number; // 화살표 크기 (치수용)
}

// 파서 레지스트리 (확장 가능한 패턴)
class EntityParserRegistry {
    private parsers: Map<string, EntityParser<any>> = new Map();

    register<T extends ParsedEntity>(type: string, parser: EntityParser<T>) {
        this.parsers.set(type.toUpperCase(), parser);
    }

    parse(entity: DxfEntity): ParsedEntity | null {
        const parser = this.parsers.get(entity.type.toUpperCase());
        if (parser?.canParse(entity)) {
            return parser.parse(entity);
        }
        console.warn(`No parser for entity type: ${entity.type}`);
        return null;
    }
}
```

```typescript
import { ParsedHatch, HatchBoundaryPath } from '@/types/cad/entity';

interface ExtrudeOptions {
    depth: number; // 돌출 깊이 (슬라이더: 0-100)
    bevel?: boolean; // 베벨 여부
    bevelSize?: number; // 베벨 크기 (기본: 0.1)
    bevelSegments?: number; // 베벨 세그먼트 (기본: 1)
}

interface Hatch3DGeometryData {
    geometry: THREE.ExtrudeGeometry;
    hatch: ParsedHatch;
    zPosition: number;
}

const DEFAULT_EXTRUDE_OPTIONS: ExtrudeOptions = {
    depth: 10,
    bevel: false,
    bevelSize: 0.1,
    bevelSegments: 1,
};

export function hatchToExtrudeGeometry(
    hatch: ParsedHatch,
    options: ExtrudeOptions = DEFAULT_EXTRUDE_OPTIONS
): THREE.ExtrudeGeometry {
    // 외곽 경계 → Shape
    const shape = boundaryToShape(hatch.boundaries[0]);

    // 홀(구멍) 처리 - 첫 번째 외곽 외 나머지는 구멍
    for (let i = 1; i < hatch.boundaries.length; i++) {
        const holePath = boundaryToPath(hatch.boundaries[i]);
        shape.holes.push(holePath);
    }

    // ExtrudeGeometry 생성
    return new THREE.ExtrudeGeometry(shape, {
        depth: options.depth,
        bevelEnabled: options.bevel ?? false,
        bevelSize: options.bevelSize ?? 0.1,
        bevelSegments: options.bevelSegments ?? 1,
        steps: getLOD3DSteps(options.depth),
    });
}

// 3D LOD Steps - 깊이에 따른 세그먼트 조절
function getLOD3DSteps(depth: number): number {
    if (depth < 10) return 1; // 얇은 돌출
    if (depth < 50) return 2; // 중간 돌출
    return 4; // 깊은 돌출
}

// HatchBoundaryPath → THREE.Path (홀용)
function boundaryToPath(boundary: HatchBoundaryPath): THREE.Path {
    const path = new THREE.Path();

    if (boundary.type === 'polyline' && boundary.vertices.length > 0) {
        const vertices = boundary.vertices;
        path.moveTo(vertices[0].x, vertices[0].y);

        for (let i = 1; i < vertices.length; i++) {
            path.lineTo(vertices[i].x, vertices[i].y);
        }

        if (boundary.closed) {
            path.closePath();
        }
    }
    // circle, arc, ellipse 타입도 유사하게 처리

    return path;
}
```

```typescript
const DEFAULT_OPTIONS: CadMaterialOptions = {
    color: '#ffffff',
    opacity: 0.7,
    side: THREE.DoubleSide,
};

export function useCadMaterial(
    mode: CadShadingMode,
    options: CadMaterialOptions = DEFAULT_OPTIONS
): THREE.Material {
    const { color, opacity = 0.7, side = THREE.DoubleSide } = options;

    return useMemo(() => {
        const baseColor = new THREE.Color(color);
        const transparent = opacity < 1;

        switch (mode) {
            case 'wireframe':
                return new THREE.MeshBasicMaterial({
                    color: baseColor,
                    wireframe: true,
                    transparent,
                    opacity,
                    side,
                });

            case 'flat':
                return new THREE.MeshPhongMaterial({
                    color: baseColor,
                    flatShading: true,
                    transparent,
                    opacity,
                    side,
                });

            case 'smooth':
                return new THREE.MeshLambertMaterial({
                    color: baseColor,
                    transparent,
                    opacity,
                    side,
                });

            case 'glossy':
                return new THREE.MeshPhongMaterial({
                    color: baseColor,
                    shininess: 150,
                    specular: new THREE.Color(0x444444),
                    transparent,
                    opacity,
                    side,
                });

            default:
                return new THREE.MeshBasicMaterial({
                    color: baseColor,
                    transparent,
                    opacity,
                    side,
                });
        }
    }, [mode, color, opacity, side]);
}

// Material 정리 유틸리티
export function disposeMaterial(material: THREE.Material): void {
    if ('map' in material && material.map) {
        (material.map as THREE.Texture).dispose();
    }
    material.dispose();
}
```

**Material 매핑 테이블:**

| Mode      | Material Class      | 주요 속성         | 시각 효과                 |
| --------- | ------------------- | ----------------- | ------------------------- |
| wireframe | MeshBasicMaterial   | wireframe: true   | 테두리만 표시             |
| flat      | MeshPhongMaterial   | flatShading: true | 각진 음영 (면별 색상)     |
| smooth    | MeshLambertMaterial | 기본              | 부드러운 음영 (정점 보간) |
| glossy    | MeshPhongMaterial   | shininess: 150    | 반사광 포함               |

#### 3D Geometry 머징 및 최적화 (Phase 2.1.8)

> **목적**: 다중 HATCH 3D 렌더링 시 성능 최적화

```typescript
// dxfToGeometry.ts 확장
import { mergeGeometries } from 'three/examples/jsm/utils/BufferGeometryUtils';

interface Merge3DOptions {
    extrudeOptions: ExtrudeOptions;
    visibleLayers: Set<string>;
}

export function mergeHatch3DGeometries(
    hatches: ParsedHatch[],
    options: Merge3DOptions
): THREE.BufferGeometry {
    const geometries: THREE.ExtrudeGeometry[] = [];

    for (const hatch of hatches) {
        // 레이어 필터링
        if (!options.visibleLayers.has(hatch.layer ?? '0')) continue;

        const geometry = hatchToExtrudeGeometry(hatch, options.extrudeOptions);
        geometries.push(geometry);
    }

    // 지오메트리 머징
    const merged = mergeGeometries(geometries);

    // 개별 지오메트리 메모리 정리
    geometries.forEach((g) => g.dispose());

    if (!merged) {
        return new THREE.BufferGeometry();
    }

    merged.computeBoundingSphere();
    return merged;
}
```

### 4.3 Error Handling & Resilience

> **목적**: 안정적인 DXF 파싱 및 렌더링을 위한 오류 처리 전략

#### 4.3.1 Graceful Degradation

| 시나리오                 | 동작                     | 복구 전략                                 |
| ------------------------ | ------------------------ | ----------------------------------------- |
| **지원되지 않는 엔티티** | Skip with `console.warn` | 나머지 엔티티 정상 파싱 계속              |
| **파싱 실패 엔티티**     | 해당 엔티티만 제외       | 오류 카운트 기록, UI에 경고 표시          |
| **폰트 로드 실패**       | Fallback 폰트 사용       | System font → Basic geometry fallback     |
| **WebWorker 크래시**     | 메인 스레드 fallback     | 최대 3회 재시도 → 작은 파일만 메인 스레드 |
| **메모리 부족**          | 부분 렌더링              | LOD 자동 다운그레이드                     |

#### 4.3.2 Error Recovery Patterns

```typescript
// 엔티티 파싱 오류 처리
function parseEntitySafe<T>(
    entity: DxfEntity,
    parser: (e: DxfEntity) => T
): T | null {
    try {
        return parser(entity);
    } catch (error) {
        console.warn(`Failed to parse ${entity.type}:`, error);
        incrementErrorCount(entity.type);
        return null;
    }
}

// WebWorker 재시도 로직
async function parseWithWorkerRetry(
    content: string,
    maxRetries = 3
): Promise<ParsedCADData> {
    for (let attempt = 1; attempt <= maxRetries; attempt++) {
        try {
            return await parseWithWorker(content);
        } catch (error) {
            if (attempt === maxRetries) {
                console.warn('Worker failed, falling back to main thread');
                return parseOnMainThread(content);
            }
            await delay(100 * attempt); // Exponential backoff
        }
    }
    throw new Error('Parsing failed');
}
```

#### 4.3.3 Font Fallback Strategy

```typescript
const FONT_FALLBACK_CHAIN = [
    { name: 'DXF_STANDARD', path: '/fonts/standard.json' },
    { name: 'SYSTEM_SANS', path: '/fonts/helvetiker.json' },
    { name: 'BASIC_GEOMETRY', path: null }, // 마지막 fallback: 점/선으로 표시
];

async function loadFontWithFallback(): Promise<Font | null> {
    for (const font of FONT_FALLBACK_CHAIN) {
        if (!font.path) {
            console.warn('Using basic geometry fallback for text');
            return null;
        }
        try {
            return await loadFont(font.path);
        } catch {
            console.warn(`Font ${font.name} load failed, trying next`);
        }
    }
    return null;
}
```
